# Food Slot Machine

A playful iOS app that turns meal planning into a game. Spin three slots to randomly combine carbohydrates, protein, and fiber-rich foods into balanced, vegetarian meal inspiration.

## Project Status

Early development — exploring the technical architecture and building the first MVP.

## Planned Features

- Three slots for food categories
- Random meal combinations
- Animated slot machine interaction
- iPhone motion gesture to trigger a spin
- Local food database and food illustrations
